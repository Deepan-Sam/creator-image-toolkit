Tool guide

Compare image file sizes after compression

The browser-based compressor re-encodes a JPG, PNG, or WebP image and reports the actual output size. Adjust quality for JPEG and WebP; PNG is encoded losslessly and may not get smaller.

Open the image compressor

The editor accepts files up to 20 MB by default. You can adjust its file-size limit.

How to use the image compressor

  1. Select an imageChoose a supported JPG, PNG, or WebP file, or drop one into the compressor on the tool page.
  2. Set quality when availableFor JPEG and WebP, move the quality slider and review the new result. PNG uses lossless output, so its quality slider is disabled.
  3. Compare the measured sizesThe tool verifies the Canvas output before displaying the resulting file size and percentage change. A larger or same-size result is reported accurately.
  4. Download the verified outputDownload the encoded copy when ready. The input image is not replaced.

Image compression questions

Will every image become smaller?

No. PNG output may stay the same size or become larger, and re-encoding a small or already optimized file may not reduce its size. The tool reports the actual comparison.

Does lowering quality change the image?

JPEG and WebP are lossy formats. Lower quality can reduce file size but can also introduce visible image degradation. Review the preview before downloading.

Does compression resize the image?

No. The compressor keeps the source image dimensions; use the image resizer to change width or height.
