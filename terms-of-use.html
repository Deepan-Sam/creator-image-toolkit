The service

Creator Image Toolkit provides browser-based tools to resize and re-encode supported images, crop images, sample image colors, prepare a 1280 × 720 thumbnail, resize images for social media, add watermarks, and create re-encoded image copies that can remove many embedded metadata fields. The image cropper, metadata cleaner, batch image resizer, and image-to-PDF tool support JPG, PNG, and WebP files. The batch image resizer applies shared dimensions and fit settings to multiple selected images, then creates individual downloads in the browser. The color picker reads pixels from supported JPG, PNG, WebP, and browser-decoded GIF still frames. Format conversion is available as an output option in the image resizer; it is not a separate processing tool. Metadata re-encoding is not a guarantee that every metadata field is removed.

Image processing takes place in the visitor’s browser using web platform features. The site does not promise uninterrupted availability or that every browser, device, file, or output format will work in every circumstance.
