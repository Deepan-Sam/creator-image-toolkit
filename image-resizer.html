Tool guide

Resize an image to the dimensions you need

Set a new pixel width and height for a JPG, PNG, or WebP image. Lock the aspect ratio to keep the original proportions, review the output, and download a separate copy.

Open the image resizer

The editor accepts files up to 20 MB by default. You can adjust its file-size limit.

How to resize an image

  1. Choose your imageBrowse for a JPG, PNG, or WebP file, or drop one into the resizer on the tool page. The browser checks the file type and size before decoding it.
  2. Enter the output dimensionsSet width and height in pixels. Keep the ratio locked to preserve proportions; unlocking it stretches the image to fit both values.
  3. Choose a format and reviewSelect a browser-supported JPEG, PNG, or WebP output. Check the generated preview, dimensions, and file size.
  4. Download the copyDownload is enabled only after the output is created and verified. Your original file remains unchanged.

Image resizing questions

How do I keep my image from looking stretched?

Keep the aspect-ratio lock enabled while changing width or height. If you unlock it, the editor fits the image to both dimensions and may stretch it.

Which image formats can I resize?

The resizer accepts JPG, PNG, and WebP files. JPEG, PNG, or WebP output options are enabled only when the browser supports that Canvas format.

Does resizing replace my original image?

No. The tool creates a new downloadable file in your browser and leaves the selected original file unchanged.
