Frequently asked questions

Are the image tools free?

Yes. The tools on this site are free to use, and you do not need an account.

Are my images uploaded?

No. The image tools process selected files in your browser. Your hosting provider may process ordinary website requests under its own policies, but the tool code does not transmit your selected image for processing.

Which file types are supported?

The tools accept JPG, PNG, and WebP files. Available output formats depend on the Canvas formats supported by your browser.

Will image compression always make a file smaller?

No. PNG output may stay the same size or become larger. Lower JPEG and WebP quality can reduce file size but may also reduce image quality. The compressor reports the measured result.

Does the thumbnail tool guarantee YouTube requirements?

No. It creates a 1280 × 720 image, but platform requirements can change. Check the official YouTube Help guidance before publishing.
