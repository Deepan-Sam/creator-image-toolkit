Privacy Policy

This policy describes what can be established from the website files reviewed on 18 October 2026. Hosting-account settings and any services added outside those files need confirmation by the site operator.

Last reviewed: 18 October 2026

Details the site operator must confirm

The website files do not identify the person or legal entity operating the site, its jurisdiction, or a privacy contact. Before relying on this as a final legal notice, confirm and publish those details, the Cloudflare account’s enabled analytics and retention settings, and any applicable local privacy requirements. Update this policy before enabling advertising.

Image processing in your browser

The resizer, compressor, and thumbnail tool use browser file, image, and Canvas features to process the image selected by the visitor. The reviewed JavaScript does not send the selected image to an image-processing server or call a third-party image API.

The browser holds the selected file and generated image data while the tool is in use. The page may display its filename, dimensions, and file size. Temporary object URLs are used for previews and outputs and are revoked when the image is cleared or the page is closed. The tools do not provide an account or save images to a site database.

These statements describe the supplied site code; browser extensions, device software, network monitoring, and hosting-level features operate separately. Avoid using the tools on a shared or untrusted device if the selected file is sensitive.

Website hosting and request information

The site is hosted as a static website on Cloudflare Pages. Like a hosting and network provider, Cloudflare may process technical request and connection information to deliver, secure, and troubleshoot the site. The files alone do not establish which Cloudflare products are enabled, the exact information processed, retention periods, or account configuration.

For information about Cloudflare’s handling of data, see the Cloudflare Privacy Policy. The site operator should confirm its Cloudflare account settings and link any applicable service-specific notices here.

Analytics, cookies, and local storage

No analytics script, advertising tag, cookie-writing code, or browser-storage call was found in the supplied HTML and JavaScript during this review. This does not verify settings configured in Cloudflare or services injected at the hosting or deployment level. The site operator should check those settings before publication.

If analytics are enabled later, this policy should be updated to identify the service, its purpose, the categories of information involved, retention and controls, and any consent choices required for visitors in relevant regions.

Privacy questions and choices

The website does not provide user accounts or an in-site privacy request form, and the supplied files do not identify a privacy contact. Depending on the laws that apply to a visitor and the site operator, people may have rights concerning personal information. The operator should confirm which rights and response duties apply and publish a working way to make a request before launch.

There is no site-provided analytics or advertising preference control in the reviewed code. If those services are enabled, add any notices, consent choices, or opt-out controls required for the services and locations involved. See the Contact page for the current contact status.

Advertising

No advertising code was found in the supplied website files reviewed. If Google AdSense or another advertising service is added, that provider may use cookies or similar technologies and process device, browser, or usage information to deliver and measure ads. The actual technologies and choices depend on the provider, account settings, visitor location, and ad configuration.

Before enabling ads, the site operator must name the advertising providers, explain their data practices and visitor controls, update this policy and any required consent experience, and review the providers’ current requirements. For Google’s general information, see Google’s advertising technologies information. No advertising service is currently represented as active by the reviewed files, and no approval or compliance outcome is promised.

External links and policy changes

The site links to external resources, including YouTube Help. Those sites have their own operators and privacy practices. This policy applies to Creator Image Toolkit, not to external websites.

This notice should be revised when the site’s code, hosting configuration, analytics, advertising, or applicable requirements change. The site operator and a contact route for privacy questions have not been supplied in the files reviewed; see the Contact page for the current status.
