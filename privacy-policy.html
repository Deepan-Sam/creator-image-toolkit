Image processing in your browser

The resizer, compressor, thumbnail tool, batch image resizer, image-to-PDF tool, image cropper, image color picker, social media image resizer, watermark maker, and image metadata cleaner use browser file, image, and Canvas features to process the image selected by the visitor. The metadata cleaner decodes and re-encodes image pixels locally; this can remove many metadata fields but does not guarantee complete metadata removal. The watermark maker also reads a selected logo image in the browser. The color picker reads the selected pixel in the browser to display its color values. The reviewed JavaScript does not send selected images, logos, or sampled pixel values to an image-processing server or call a third-party image API.

The browser holds the selected file and generated image data while the tool is in use. The page may display its filename, dimensions, and file size. Tools that use temporary object URLs for previews or outputs revoke them when the image is cleared or the page is closed; the color picker instead uses an in-memory decoded image and a small sampling canvas. The picker’s recent-color history is kept only in page memory and is cleared when another image is selected or the page is closed. The tools do not provide an account or save images to a site database.

These statements describe the supplied site code; browser extensions, device software, network monitoring, and hosting-level features operate separately. Avoid using the tools on a shared or untrusted device if the selected file is sensitive.
