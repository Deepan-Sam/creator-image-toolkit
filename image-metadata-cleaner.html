Important: The image is processed in this browser; it is not uploaded for image processing. Re-encoding usually removes many embedded EXIF, GPS, and text metadata fields, but browser encoders can behave differently. This tool does not inspect or certify every metadata block, and should not be treated as a forensic privacy guarantee. Keep the original if you need its metadata.

How it works

  1. Choose a supported image from your device.
  2. Select PNG, JPEG, or WebP output.
  3. Create and review the re-encoded copy.
  4. Download it only after checking the preview and file details.

What does re-encoding change?

The browser decodes the image pixels and creates a new file from those pixels. This can remove many metadata fields carried by the original file. It may also change compression, quality, file size, color characteristics, and transparency depending on the selected format and browser.

For sensitive images, verify the downloaded file with a trusted metadata inspection tool before sharing. This utility does not guarantee that every possible metadata field is removed.
