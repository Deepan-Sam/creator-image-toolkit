How to pick a color from an image

  1. Choose an imageSelect or drop a JPG, PNG, WebP, or GIF file. The image is decoded and sampled in your browser.
  2. Select a pixelClick or tap the image, or focus it and use the arrow keys. Press Enter or Space to sample the keyboard position.
  3. Copy a color valueReview the HEX, RGB, HSL, or RGBA value and use its Copy button. For a transparent pixel, RGBA includes the alpha channel.

GIF files are sampled as one browser-decoded still frame; animation is not sampled. Color values describe the decoded pixel, which can differ from an image’s embedded color profile.

Images and sampled pixel values stay in this page’s browser memory. They are not uploaded to an image-processing server or saved by this tool.
